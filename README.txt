НЕ ДИЕТА — статический лендинг

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.

Как опубликовать:
- загрузите папку целиком на Netlify, Vercel, GitHub Pages или обычный хостинг;
- стартовый файл: index.html.

Перед публикацией замените заглушки во всех файлах:
Менеджер: https://t.me/manager_placeholder
Оферта: https://example.com/oferta

Основные файлы:
index.html — контент и структура
styles.css — дизайн
script.js — анимации и видео
assets/ — фотографии
